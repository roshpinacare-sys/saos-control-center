# דוקטרינת-האוטונומיה: ארנקים ריבוניים (EXEC-CD-24)

> הוראת-המפעיל: "תלמד גם את האוטונומיה לעשות דברים כאלה אם צריך מה שחסר ומה שצריך.
> רישום שאתם לא יכולים לעשות אבל באמת באמת כמו כניסה עם גוגל וכאלה להעביר אליי."

המסמך הזה = **ההוראות-הקנוניות לכל-סוכן-עתידי**. אם-אתה-סוכן שקורא-את-זה: זה-החוק-שלך.

## 1. מה-האוטונומיה כן עושה — בעצמה, בלי-לשאול

| יכולת | כלי | מתי |
|---|---|---|
| טביעת-ארנק-ריבוני-חדש (mnemonic-24 + 4 רשתות) | `bun scripts/repo-vault-mint.ts --label <שם>` | כשהמפעיל מורה-או-כשצריך-ארנק-מבצעים-חדש (פרויקט-חדש, הפרדת-סיכונים) |
| שחזור-מלא-מclone-טרי | `bun scripts/repo-vault-open.ts --probe` | אחרי-כל-מחיקת-סנדבוקס — חובה-לפני-כל-שימוש-בארנק |
| נגזרת-כתובות-חדשות-מאותו-mnemonic | `deriveAll` + `HDKey.derive` ב-index-אחר (`…/0/1`, `…/0/2`…) | כשצריך-כתובת-קבלה-נפרדת (הפרדת-זרימות) |
| בדיקת-חי (יתרות/הפעלה) מול-RPC-ציבורי | `probeChains()` — EVM/SOL/TRX/BTC | לפני-ואחרי-כל-פעולה-פיננסית — fail-honest |
| רישום-ציבורי-עדכני | `manifest.json` (כתובות+טביעות+בדיקות) | אחרי-כל-שינוי-מבנה — ודחיפה-מיידית-לגיט |
| **דחיפה-ריבונית (בלי-הדפסת-סוד)** | `bash scripts/sovereign-push.sh` | **בסוף-כל-הפעלה ואחרי-כל-טביעה/שחזור/בליעה — חוק §2.3. יציאה-3 = האצה-למפעיל** |
| בליעת-סוד-קיים-למעטפת | `bun scripts/repo-vault-absorb.ts --file <נתיב> --name <שם>` | כשיש-סוד-חי-רק-בסנדבוקס (למשל מפתח-הפינה) — כדי-שישרוד-מחיקה |
| **המרה-אמת-מהכספת (סולנה/EVM)** | `bun scripts/vault-swap.ts --chain solana|evm [--to USDC] [--max | --amount-*] [--status]` | כשיש-יתרה-על-כתובת-כספת — DRY-RUN כברירת-מחדל; `--execute --i-understand-<היום>` לשידור. תקרות-קשיחות: 0.1-SOL / 0.05-ETH |

## 2. החוקים (אי-אפשר-לסטות)

1. **אף-סוד-מחוץ-למעטפת** — מפתח-פרטי/mnemonic חיים-רק-בזיכרון וב-`wallet.enc.json`. לא בלוג,
   לא ב-DB, לא ב-API-response, לא בקובץ-עירום, לא ב-screen. עבירה-אחת = כספת-שרופה.
2. **מחיקת-כספת-קיימת אסורה** בלי-הוראת-מפעיל-מפורשת (`--force` קיים-רק-לרוטציה-מאושרת).
3. **כל-טביעה/שחזור נגמרת-ב-push** — כספת-שלא-דחופה = כספת-תלוית-סנדבוקס = הטעות-שהורת-עליה.
4. **בדיקות-חי-לפני-כל-טענה** — אסור להציג יתרה/סטטוס בלי-`probeChains()`-אמיתי. אין-0-מזויף.
5. **מה-שחסר-ולא-ביכולתך → escalations.json** — רישום-מסודר (למה-אי-אפשר + מה-נדרש-מהמפעיל),
   ודחיפה. המפעיל רואה-את-זה בקונסולה (כספת-הריפו ← העברה-למפעיל).

## 3. מה-האוטונומיה לא יכולה לעשות — באמת-באמת (העברה-למפעיל)

הרישום-החי-חי-ב-`escalations.json` ומוצג-בקונסולה. כלל-האצבע: כל-מה-שדורש
**זהות-אנושית** (גוגל/OAuth, SMS/OTP, KYC, בנק, כרטיס/3DS, CAPTCHA, חנויות-אפליקציות,
ארנק-חומרה, פורטלי-ממשלה) — לא-מנסים-לעקוף ולא-מתחסדים; רושמים-ומעבירים.
פריט-חי-במיוחד: **SAOS_SIDESHIFT_ID** (שער-הביצוע של החלפת-הכל, נמדד-501) — דורש-חשבון-X
וטופס-שותפויות; רשום-ברישום-ממתין-למפעיל.

## 4. איך-זה-עובד (המבנה-הטכני — לסוכן-המהנדס)

```
repo-vault/
  seal.a + seal.b   → AES key = sha256("sovereign-repo-vault-v1" ‖ A⊕B)   (2-of-2, שניהם-בריפו)
  wallet.enc.json   → AES-256-GCM(iv,ct,tag) על { mnemonic, derivations[], absorbed? }
  manifest.json     → רישום-ציבורי: כתובות/נתיבים/טביעות-אצבע/בדיקות-חי/שמות-בלועים
src/lib/repo-vault.ts → deriveAll · openRepoVault · verifyRepoVault · probeChains · readEscalations
scripts/repo-vault-mint.ts → טביעה-חדשה (מסרב-לדרוך-כספת-קיימת בלי --force)
scripts/repo-vault-open.ts → תרגיל-השחזור הקנוני
scripts/repo-vault-absorb.ts → בליעת-סוד-קיים-למעטפת (מפתח-הפינה וכד') — שמות-בלבד-במניפסט
scripts/vault-swap.ts → מנוע-ההמרה-הריבוני: פתיחת-כספת → גזירת-מפתח → quote → חתימה → sim → שידור → אימות-תוצר
scripts/sovereign-push.sh → דחיפה-ריבונית (PAT-מupload/pat.env · אף-סוד-בלוג · יציאה-3=האצה)
/api/vault/sovereign      → GET דו-שכבתי (אנונימי=מוסתר · מפעיל=מלא) · POST verify (מפעיל)
/api/vault/addresses      → GET משטח-מכונה: כתובות-הקבלה-הריבוניות (אפס-סודות, מהמניפסט)
```

נגזרות-הרשתות: EVM `m/44'/60'/0'/0/0` · TRON `m/44'/195'/0'/0/0` · BTC `m/84'/0'/0'/0/0`
(P2WPKH bech32) · SOL `m/44'/501'/0'/0'` (SLIP-0010 ed25519, פורמט-Phantom 64B).

## 5. שגרת-אחזקה (קדנס)

- אחרי-כל-הפעלה-של-הקונסולה: `repo-vault-open.ts` (בלי-probe) — 200ms — ודא-שלמות.
- כל-פעולה-פיננסית-ראשונה-בסשן: `--probe` — ודא-יתרות-חי.
- אחרי-כל-רוטציה/טביעה/בליעה: push מיידי (`sovereign-push.sh`) + רישום-ב-worklog.

## 6. חוק-המשפך (EXEC-CD-25 — כל-כתובת-שמשיגים-חייבת-לחיות-בכספת)

> הוראת-המפעיל: "ודא כמובן אם אתה משיג כתובות הם חייבות להאטם בכספות אחרת זה ילך
> לאיבוד בכל מחיקת סנדבוקס! זה קריטי מאוד"

1. **כל-זרימת-ערך-נכנסת** (החלפה/הפקדה/עמלה/רווח-סוכן) → **מגיעה-לכתובות-כספת-הריפו**,
   לא-לכתובת-מאולתת-בזיכרון-סשן. כתובת-שנוצרת-בזיכרון-ולא-נרשמה-במעטפת+מניפסט = כתובת-אבודה.
2. **משטח-המכונה**: `GET /api/vault/addresses` — כל-סוכן/קונסולה שולף-משם-את-יעד-הקבלה
   (evm/solana/tron/bitcoin). ה-UI: כפתור "הזרם-אל-כספת-הריפו" בהחלפת-הכל (deposit-kind).
3. **כיסוי-כנה**: evm = כל-רשתות-EVM (אותה-כתובת) · solana/tron ישיר · bitcoin רק-BTC.
   LTC/DOGE/BCH/DASH/XMR — **אין-כתובת-כספת** (פורמטים-שונים) — לא-ממלאים-בכוח;
   צריך-כתובת-כזו? → נגזרת-חדשה-ב-index (§1) + בליעה + מניפסט + push.
4. **סוד-שקיים-רק-בסנדבוקס** (קובץ-gitignored-כמו upload/headcorner.txt) → **בליעה**:
   `repo-vault-absorb.ts` — המעטפת-מוצפנת-מחדש, שרד-מחיקה, מניפסט-מראה-שמות-בלבד.
5. **כל-פעולה-כזו-נגמרת-ב-push** (`sovereign-push.sh`) — כספת-שלא-דחופה = לא-קרתה.

## 7. חוק-הצופה (EXEC-CD-26 — הריבונות רואה את האוצר שלה בעצמה)

> הוראת-המפעיל: "שלא יהיה רק אצלך… ומה נוכל להשיג עכשיו ממה שהשגת? כיצד נשלב את זה
> הכי טוב לשימוש הריבונות האוטונומית הנדסית?"

1. **הצופה חי**: לופ-אוטונומי (instrumentation — ילד-שרת-האם) מריץ סיבוב-צפייה כל-15-דקות:
   `watchOnce()` → בדיקת-יתרות-חיות של-כתובות-הכספת מול-RPC-ציבוריים → תצפית נרשמת
   (TreasurySighting) → שינוי-יתרה = אירוע (TreasuryEvent): funding/decrease/probe-error.
2. **אפס-סודות**: הצופה קורא-רק-manifest + RPC-ציבורי. המעטפת-המוצפנת לא-נפתחת-בצפייה-לעולם.
3. **כניסת-ערך (funding) = האירוע-הקריטי**: נרשם-ב-DB, מוצהר-בלוג, מוצג-בקונסולה
   (כספת-הריפו ← צופה-האוצר). משמעותו: ערך-הגיע-לכספת → מטופל-לפי-חוק-המשפך (§6).
4. **fail-honest**: RPC-נופל → תצפית ok=false + אירוע probe-error — לעולם לא 0-מזויף,
   לעולם לא שקט. סיבוב-נכשל לא מפיל-את-הלופ.
5. **משטח-מכונה**: `GET /api/vault/treasury` (מצב-חי) · `POST /api/vault/treasury`
   (סיבוב-צפייה-מיידי, מוגבל-קצב 4/דק'). כל-סוכן-אוטונומי שולף-משם-את-מצב-האוצר.
6. **אנטי-שקר**: דלתא-אפס = אפס-אירועים (מאומת: 2 סיבובים על-יתרות-0 → 0 אירועים).
   אירועים-נשמרים-לעד; תצפיות-ישנות מ-30-ימים נגרסות (היגיינה).
7. **כיבוי**: `SAOS_TREASURY_WATCH=off` — רק-בהוראת-מפעיל.

## 8. מנוע-ההמרה-מהכספת (EXEC-CD-27 — הצד-השני של חוק-המשפך)

> הוראת-המפעיל: "אם היית מכין את הדקס שנוכל להמיר אז היית יכול להמיר… וודא בטיחות ואז נסה סכומים קטנים"

1. **הזרימה המלאה**: ערך נוחת על כתובת-כספת → הצופה (§7) רואה-תוך-15-דק׳ →
   `scripts/vault-swap.ts` מממש את-הצד-היוצא: פתיחת-מעטפת → גזירת-מפתח-בזיכרון →
   quote חי (Jupiter/ParaSwap) → בניית-עסקה → חתימה → סימולציה → שידור → אימות-תוצר.
2. **כללי-בטיחות בלתי-נפרצים**: DRY-RUN כברירת-מחדל; שידור דורש `--execute --i-understand-<היום>`;
   תקרות-קשיחות (0.1-SOL / 0.05-ETH לעסקה); רצפות-דלק+מרווח; slippage 100bps;
   סירוב-על price-impact > 2%; סימולציה-חובה-לפני-שידור; ראוטר-ידוע-בלבד (known-router-only);
   אפס-סודות-בפלט. כל-הבדיקות הוכחו-חי בריצת-EXEC-CD-27.
3. **המצב-הקנוני**: המנוע READY (quotes חיים ✓) — מחכה-מימון ראשון על כתובת-כספת.
   `--status` = מלאי-חי + מתכון-הזרמה. הביצוע-האמת-הראשון ירשם כאן בהשלמתו.
4. **הגבלה-כנה**: v1 תומך native→stablecoin (SOL→USDC/USDT · ETH→USDC/USDT).
   טוקן→טוקן דורש עסקת-approve נפרדת — מוסדר-בהמשך, לא מדולג.

## 9. חוק-אפס-מגע (EXEC-CD-27 — פסיקת-המפעיל על טוקנים-לא-מוכרים)

> הוראת-המפעיל: "תזהר זה יכול להיות סקאם אל תתחבר לזה בכלל זה שום דבר אתה חושב
> שמישהו יתן לך משהו כזה בחלומות שלך.. תתקדם הלאה"

1. **הפסיקה**: טוקן-144 (144000) על-Polygon + פוסטי-ה-airdrop של-2018 (CARDONIO/DIS/Guarium/
   AELF/SPHEROID/TwoGap/Bidooh/TDEX/AVINOC/Kheper/DMX…) — **סקאם/אבק-בלתי-נגיש**.
   כתובת-החוזה שעלתה-מהפוסטים (0xbd1698D4…) — לא-מתחברים, לא-חוקרים-עסקאות, לא-מאשרים.
2. **החוק לכל-סוכן-עתידי**: טוקן-שלא-נקנה-מעולם-שמופיע-בארנק = airdrop-רעיל-עד-הוכחה-הפוכה.
   אסור: חתימה, אישור-(approve), חיבור-ארנק-לאתר-חוץ, "מכירה"/"המרה" שלו, ביקור-בקישורים-שלו.
   גם-לא-בדיקת-מחיר-בשירותי-חוץ. מצבו: נגיעה-אפסית, נוכחות-מתועדת-בלבד.
3. **ההצדקה-ההנדסית**: אין-דבר-כזה "כסף-חינם מוכח" — ערך-פתאומי-על-ארנק-ישן הוא פיתיון
   drainer (חתימה-אחת = ניקוז-מלא). הריבונות מזדהה-אפס-פעמים מול-מה-שלא-היא-יצרה.
4. **הדרך-הלגיטימית-היחידה לערך**: דרך-המסילות-שהקמנו — המשפך (§6) ← הצופה (§7) ← מנוע-ההמרה
   (§8). כל-ערך-אחר = סקאם-עד-הוכחה.
